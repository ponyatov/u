# `μ`
## virtual cluster OS

(c) [[Dmitry Ponyatov]] <<dponyatov@gmail.com>> 2025 [[license/MIT|MIT]]

github: https://github.com/ponyatov/u

- bytecode/stack VM
	- AOT bytecode compiler
		- MCU-enabled (ESP32, Cortex-M)
	- embedded Linux (RPi)
	- desktop/server host OSes (Linux, Win, MacOS?)
- micro/embedded script engine
	- FORTH-inspired on-device REPL
- tiny portable GUI (SDL-based, no host OS integration)
